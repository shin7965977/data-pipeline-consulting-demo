# Domain Configuration

This repository follows a **single-context** domain layout.

- Domain glossary lives at the repository root: [`CONTEXT.md`](../../CONTEXT.md).
- Architecture Decision Records live under: [`docs/adr/`](../adr/).

All engineering skills and implementing agents must consult `CONTEXT.md` for canonical terms (`Customer`, `Order`, `GMV`, `Net Revenue`, `AOV`, `LTV`) and respect accepted ADRs before proposing schema or architectural changes.
