Streamlit Executive Strategy Cockpit

Powered by dashboard.py, providing C-suite leadership with interactive P&L simulations, SKU Pareto 80/20 optimization, customer RFM segmentation, and an autonomous FastMCP Gemini AI Decision Copilot.

1. 📱 4-Pillar Decision Modules in dashboard.py

📊 1. Sales & P&L Analysis

Real-time GMV, Net Realized Cash, Average Order Value (AOV), and cancellation rate waterfall leakage breakdowns.

📦 2. SKU Pareto 80/20

Cumulative revenue curves classifying inventory into Core Drivers (Top 20%), Growth, and Long-Tail Dead Stock.

👥 3. Customer RFM & LTV

Recency, Frequency, Monetary clustering identifying Champions, Loyalists, and At-Risk customer retention cohorts.

🤖 4. FastMCP AI Decision Hub

Google Gemini Flash 2.5/3.6 tool calling delivering MBB-grade root cause diagnostics and natural language chart generation.

2. 🚀 Running the Cockpit Locally

Clone the repository and launch the application in your local environment in 2 steps: 

# 1. Install dependencies
pip install -r requirements.txt

# 2. Run the interactive Streamlit app
streamlit run dashboard.py

The app will automatically open in your default browser at http://localhost:8501 with full DuckDB / BigQuery data connection support.

3. ☁️ Google Cloud Serverless Architecture

  • Near-$0/Month Idle Cost: Packaged as a lightweight container orchestrated via Cloud Run Jobs and Cloud Workflows.
  • Zero Data Movement: Direct SQL pushdown to Google BigQuery Gold tables (platzi_gold) with in-memory caching.
  • FastMCP Agent Guardrails: Strict input sanitization defending against off-topic injection and hallucination.
