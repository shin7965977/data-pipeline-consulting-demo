Streamlit 商業決策駕駛艙導覽

由 dashboard.py 驅動，為管理階層提供即時損益模擬、商品 SKU Pareto 80/20 排行、顧客 RFM 分群，以及結合 FastMCP 與 Google Gemini 的 AI 決策副駕駛。

1. 📱 dashboard.py 四大核心決策面版

📊 1. 損益與營收分析

即時追蹤 GMV、實收淨營收、平均客單價（AOV）與訂單取消率漏斗損耗。

📦 2. 商品 Pareto 80/20

累積營收曲線將商品分類為主力帶貨商品（前 20%）、成長型商品與呆滯庫存商品。

👥 3. 顧客 RFM 分群與 LTV

依據最近購買、購買頻率與消費金額分群，精準鎖定 VIP 忠實客與流失預警名單。

🤖 4. FastMCP AI 決策中樞

整合 Google Gemini Flash 工具呼叫，提供 MBB 顧問等級的根本原因診斷與自然語言圖表生成。

2. 🚀 本地快速啟動方式

複製本專案後，只需兩行指令即可在本地電腦啟動互動儀表板： 

# 1. 安裝必要套件
pip install -r requirements.txt

# 2. 啟動互動式 Streamlit 應用程式
streamlit run dashboard.py

終端機將自動為您開啟瀏覽器頁面 http://localhost:8501，完整支援 DuckDB 與 Google BigQuery 混合模式。

3. ☁️ Google Cloud 零維運無伺服器架構

  • 近 $0/月 閒置成本：包裝為輕量容器，由 Cloud Workflows 與 Cloud Run 按需喚醒執行。
  • 零數據搬遷：直接以 SQL 下推查詢 Google BigQuery Gold 層市集（platzi_gold）。
  • FastMCP 防護欄：嚴格限制 Agent 僅能查詢經核准之指標，防範幻覺與越權操作。
